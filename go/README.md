# One clock

T0 is **2026-11-07T19:00:00Z**, which is **20:00 CET**. The window ends **21:00 UTC / 22:00 CET**.

There is one sender. The desk. The mini counts. The box is not part of this window.

GO-BUILD and GO-MINI are the paste. Open the file and paste the whole sheet. Pasting a run sheet before Saturday does not start the sender and does not start the counter. The counter starts at 18:58 UTC (19:58 CET) on Saturday. [GO-BOT](GO-BOT.md) says the box has no task. Do not paste it as a job.

Abort before T0 if a check at 18:40 UTC fails: sync, peers, clock, miners, the relay, or the lane under 2,500 coins or 18,000 usable tKAS. Do not lower that line.

The desk sheet and the mini sheet are plan 1 in [plan/ROADMAP.md](../plan/ROADMAP.md). The box sheet is the record that the box is not in the window. The count plan is [plan/COUNT.md](../plan/COUNT.md). It is in force, and it does not move the clocks in these sheets. A later note in the repo can replace it. The load after 21:00 UTC has its own sheets in [after/](../after/README.md) and does not replace these.
